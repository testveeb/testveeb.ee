# Day-Zero Startup Idea Generator

A simple, elegant web application that generates random, market-tested startup ideas for non-technical entrepreneurs. Built as a single-page MVP utilizing HTML, JavaScript, and Tailwind CSS.

## Features
- **Randomized Idea Generation**: Combines target audiences, problems, and technologies to produce unique startup concepts.
- **Modern UI**: Uses Tailwind CSS with a glassmorphism design, dark mode aesthetics, and responsive layout.
- **Instant Feedback**: Ideas are generated instantly on the client side with smooth transitions.

## Setup
Since this is a client-side application, no backend or build step is required.

1. Simply serve `index.php` (or rename to `index.html`) using any web server.
2. Open the file in your browser to start generating ideas!

## Customization
You can easily add more audiences, problems, or technologies by editing the arrays in the `<script>` section of the file.
