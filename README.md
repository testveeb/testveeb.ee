# Day-Zero Startup OS

A simple, elegant web application that generates random, market-tested startup ideas for non-technical entrepreneurs, and then automatically scopes out the MVP technical architecture and feature roadmap.

## Features
- **Randomized Idea Generation**: Combines target audiences, problems, and technologies to produce unique startup concepts.
- **MVP Scoping & Architecture Engine**: Automatically generates a recommended tech stack (Frontend, Backend, Database, Hosting) and a 3-phase feature roadmap (MVP, Growth, Scale) based on the idea.
- **Modern UI**: Uses Tailwind CSS with a glassmorphism design, dark mode aesthetics, and responsive layout.
- **Instant Feedback**: Everything runs instantly on the client side with smooth transitions.

## Setup
Since this is a client-side MVP, no backend or build step is required.

1. Simply serve `index.php` (or rename to `index.html`) using any web server.
2. Open the file in your browser to start generating and scoping ideas!
